# ZenovOS 0.1.1 VM Image 1

**Published:** 31 July 2026  
**Tag:** [`v0.1.1-vm1`](https://github.com/xemoll/zenov-os/releases/tag/v0.1.1-vm1)  
**Source commit:** [`9353bacdabfa8383fd885564be2336d5452d6faf`](https://github.com/xemoll/zenov-os/commit/9353bacdabfa8383fd885564be2336d5452d6faf)  
**Target:** legacy BIOS, 32-bit x86 virtual machines

This is the first ZenovOS 0.1.1 distribution that can be attached directly as a virtual CD/DVD. It is separate from the immutable original `v0.1.1` release because the ISO was built from the substantially newer exact source commit listed above.

## Recommended downloads

Download both files:

- `ZenovOS-0.1.1-x86.iso` — bootable ISO 9660 / El Torito optical image;
- `ZenovOS-0.1.1-data.img` — writable 16 MiB ZenovFS disk for files, settings, packages and audit state.

The ISO is read-only. Persistent state is stored on the data image.

## Virtual-machine configuration

| Setting | Value |
| --- | --- |
| Architecture | 32-bit x86 / i686 |
| Firmware | Legacy BIOS; disable EFI/UEFI |
| Memory | 64 MiB recommended |
| Optical drive | `ZenovOS-0.1.1-x86.iso` |
| First IDE hard disk | `ZenovOS-0.1.1-data.img` |
| Boot order | Optical drive first |

QEMU:

```bash
qemu-system-i386 \
  -m 64M \
  -drive file=ZenovOS-0.1.1-data.img,format=raw,if=ide,index=0,media=disk \
  -drive file=ZenovOS-0.1.1-x86.iso,format=raw,if=ide,index=2,media=cdrom,readonly=on \
  -boot order=d,strict=on
```

## Current limitations

- This is a live boot ISO, not a hard-disk installer.
- Legacy BIOS is required; UEFI boot is not implemented.
- Persistent state requires the separate writable data image.
- QEMU is the automated acceptance target.
- VirtualBox and VMware are documented compatibility targets but are not exercised in CI.
- Physical-hardware installation is not supported by this image.
