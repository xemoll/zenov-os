# ZenovOS 0.1.1 Live ISO 1

Release tag: `v0.1.1-live1`

## Download

The release intentionally contains exactly one file:

- [`ZenovOS-0.1.1-x86.iso`](https://github.com/xemoll/zenov-os/releases/download/v0.1.1-live1/ZenovOS-0.1.1-x86.iso)

No ZIP extraction and no companion disk are required.

## Start in a virtual machine

Create a 32-bit virtual machine with:

| Setting | Value |
| --- | --- |
| Firmware | Legacy BIOS, EFI disabled |
| CPU | 1 virtual CPU |
| Memory | 64 MiB or more |
| Display | Standard VGA / VBoxVGA-compatible |
| Storage | ISO attached as virtual CD/DVD only |
| Boot order | Optical drive first |

Start the VM. ZenovOS automatically loads the embedded system image, mounts a writable Live session and opens the graphical desktop.

QEMU example:

```bash
qemu-system-i386 \
  -machine pc,vmport=off \
  -m 64M \
  -vga std \
  -drive file=ZenovOS-0.1.1-x86.iso,format=raw,if=ide,index=2,media=cdrom,readonly=on \
  -boot order=d,strict=on
```

For a host without AMD-V/VT-x, add software emulation:

```bash
qemu-system-i386 \
  -accel tcg,thread=multi \
  -machine pc,vmport=off \
  -m 64M \
  -vga std \
  -drive file=ZenovOS-0.1.1-x86.iso,format=raw,if=ide,index=2,media=cdrom,readonly=on \
  -boot order=d,strict=on
```

## Live-session behavior

Files and settings are writable while ZenovOS is running. The storage layer uses the embedded ZenovFS image as an immutable base and redirects changed sectors into RAM. Changes reset after reboot or power-off.

## Publication contract

The release is published only after the exact source commit passes:

- deterministic embedded-image generation;
- no-disk optical boot;
- graphical desktop readiness;
- Live-session write/read/fsck/sync;
- deterministic ISO rebuild;
- El Torito validation;
- one-asset release enforcement;
- unauthenticated public ISO download and byte comparison.

Older VM releases remain historical and retain their original files. `v0.1.1-live1` is the current ISO-only distribution.
